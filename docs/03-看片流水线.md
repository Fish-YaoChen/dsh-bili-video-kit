# 03 · 看片流水线

一条片子从「一个链接」变成「我能说出它讲了什么」，走的是固定的五步。跳步必翻车。

## 顺序

```
video_probe  →  video_storyboard（分段）  →  video_zoom（选做）
                                        →  video_locate（选做）
                  字幕只有烧进画面的？      →  video_subtitles
```

### 1. `video_probe`：先知道它是什么

一个问题：**多长、有没有音轨、有没有字幕轨、多少分辨率。**

不知道多长就去扫整片，等于闭着眼睛付款。时长出来了，再决定分几个窗口读。

### 2. `video_storyboard`：按窗口读，不按整片读

长片一定分窗口读，跟着它每次返回的 `next` 走：

```
video_storyboard({ input, from: 0,   segment: 300 })
video_storyboard({ input, from: 300, segment: 300 })
```

每格都带时间区间和编号，可以指着某一格说话（「第 7 格，02:12 那一下」）。

**尺寸策略怎么选**：

| 策略 | 什么时候用 |
|---|---|
| `auto`（默认） | 绝大多数情况。它会自己挑最便宜且能读的那档 |
| `compact` / `skim` / `brief` | 只想看骨架、判断值不值得细读 |
| `full` | 你明确要更大的格子。**注意：`full` 是更贵，不是更全** |

机器快剪的合集（一秒钟好几个切）在 `compact` 下只剩骨架，读字必须单独 `video_zoom`。

### 3. `video_zoom`：认字、认脸用

窗口越小越好（几秒到十几秒），一次最多几十帧。用在：

- 画面里的小字、片尾名单、卡片标题
- 想确认一句字幕原文
- 需要看清是谁

### 4. `video_locate`：记得台词，忘了时间

给一句话，它返回带时间戳的转写行，按匹配度排序；拿到了再拿时间点去 `video_zoom`。**纯文本，不解码画面**，所以便宜。

### 5. `video_subtitles`：只有烧进画面的字幕

PV、歌词、双语标题这类：没有字幕轨，ASR 也认不出（唱、混音、异语种）。它把每 3 秒的字幕带切下来，按时间顺序拼成一张竖图——**空白的一格也是信息**（那一刻没字幕）。

## 转录（耳朵）：本机 SenseVoice

插件只认两种后端：宿主的 `speechToText` 服务，或一个 OpenAI 兼容的 `/audio/transcriptions`。后者自己起：

```bash
node scripts/asr-server.cjs
```

配置写 `~/.dsh/asr.json`（模板见 `scripts/asr.example.json`）：

```json
{
  "baseUrl": "http://127.0.0.1:8123/v1",
  "model": "sensevoice-onnx",
  "language": "zh",
  "manage": {
    "start": ["node", "<绝对路径>/scripts/asr-server.cjs"],
    "idleMs": 60000, "waitMs": 60000, "healthPath": "/health"
  }
}
```

三条契约（照上游 `docs/asr-contract.md`）：

1. **`segments` 的 `start`/`end` 必须相对本次上传、从 0 起。** 返回绝对时间会让每格台词错位
2. **没有 `segments` 会被退化成一整块**，所以服务端一定要给
3. **要能 `POST /shutdown`**：插件空闲时会发这个请求（`idleMs` 到了自己退）

本机地址**不需要 key**。反过来，看见 `no key` 先别怀疑机器没有语音识别能力——多半是 `baseUrl` 指到外网去了，或者那一层没注册上。

### 服务端环境变量

| 变量 | 作用 |
|---|---|
| `ASR_NODE_MODULES` | `sherpa-onnx-node` 所在的 `node_modules` |
| `ASR_MODEL_DIR` | SenseVoice 模型目录（含 `model.int8.onnx`、`tokens.txt`） |
| `ASR_LOG_DIR` | 日志目录，默认系统临时目录 |
| `ASR_PORT` / `ASR_IDLE_MS` | 端口（默认 8123）/ 空闲退出时间 |

## 一条铁律：ASR 是听出来的，不是看到的

转写会把人名、缩写、专名听岔，而且**听岔得很自信**：

- `Knight` → `night`
- `BLG` → `BG`
- 中文也照岔：`脆薯眉` → `脆乳梅`

所以：**凡是要写进结论的专名，一律回画面核一遍。** 核不上就标「待核」，别把听岔写成事实。这条比前面所有技巧都重要——它决定你说出来的话能不能被人信。
