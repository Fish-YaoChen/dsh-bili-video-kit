# 01 · 装故事板插件

插件是上游项目：[SAOS-3624/dsh-video-storyboard](https://github.com/SAOS-3624/dsh-video-storyboard)。**本仓库不含它的代码**，装和升级都按上游的说明走。

## 装完先确认工具在

在 DSH 里能调用这些工具就说明装上了：

| 工具 | 一句话 |
|---|---|
| `video_probe` | 只读容器信息：时长、分辨率、帧率、音轨、字幕轨。不解一帧，几乎不花钱 |
| `video_storyboard` | 分镜拼图 + 文本索引。核心工具 |
| `video_zoom` | 一小段放大重读，认字、认脸 |
| `video_locate` | 按台词找时间点（纯文本） |
| `video_subtitles` | 把烧进画面的字幕带切条拼成一张竖图 |
| `video_storyboard_settings` | 打开本地设置页（ASR 开关、端点、key） |

## 版本要留意

同一台机器上如果 `desktop` 和 `web` 两个 profile 都装了它，版本可能不一样（比如桌面端 `0.7.5`、web 端还是 `0.4.5`）。行为对不上时先查版本，别拿两个版本互相证明。

```bash
# 看装在哪、是哪个版本
cat ~/.dsh/profiles/desktop/node_modules/dsh-video-storyboard/package.json | grep '"version"'
```

## 它自带的两份文档，值得先读

装好之后包里有：

- `docs/asr-contract.md` —— 转录后端要满足什么（`segments` 必须相对本次上传、从 0 起；要支持 `POST /shutdown`）
- `docs/CONFIG.zh.md` —— 配置项与后端优先级

本仓库的 ASR 服务就是照这份契约写的，读一遍再看 [03-看片流水线.md](03-看片流水线.md) 会顺很多。

## 钱的事

- `video_probe` 不解码，基本免费
- `video_storyboard` 按**图片像素**计费，**文本索引往往比图更贵**——想省钱先 `dryRun: true` 报价，再决定要不要真跑
- 策略不是越大越好：`auto` 已经会挑最便宜且能读的那种，`full` 是「更大更贵」，不是「更全」
